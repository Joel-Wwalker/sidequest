# Context-first encyclopedia expansion

**Goal:** Expand SIDEQUEST toward 500 distinct ingredients with sourced summaries and scenes designed around a credible use context.

**Architecture:** Preserve the original 19 scenes. Add typed catalog records that explicitly specify context, activity, therapeutic or experimental intent, mechanism, reaction, downside and sources. Compose new scenes from bounded setting, action and mechanism components; all moving layers share the existing clock. Brands are aliases, not additional entries.

**Tech stack:** Existing React/TypeScript/SVG application, Node 24 tests, Sites hosting and GitHub CI.

## Review focus

Context is a scene premise, not a claim that every user shares it. Medical scenes should represent treatment rather than automatically implying intoxication. Experimental compounds must not depict unproven benefits as established outcomes. Avoid false precision, dosing instructions, duplicated ingredients and brand-count inflation. The review log must distinguish complete reviewed coverage from representative evidence and unresolved items.

The final coverage pass adds six common omissions (heroin, methamphetamine, GHB, GBL, nandrolone and stanozolol) for a bounded target of 506 entries. Brands and salts remain aliases. This follows the user's approximate 500-entry goal; final verification must include these common substances.
